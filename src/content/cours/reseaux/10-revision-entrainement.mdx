## Mode d'emploi

Ce chapitre complète les [fiches et quiz par notion](/cours/reseaux/revision-fiches-et-quiz/). Tout ce que vous faites ici (cases cochées, cartes sues ou à revoir, meilleur score) reste **dans votre navigateur** : rien n'est envoyé, et vous retrouvez votre avancement en revenant sur la page, même hors ligne une fois le site installé.

Un ordre de travail possible :

1. cochez dans la liste ci-dessous les notions que vous savez déjà **réexpliquer sans regarder** ;
2. révisez les autres avec leur fiche, puis avec les flashcards (filtre par thème, puis « À revoir seulement ») ;
3. entraînez-vous sur les calculs (sous-réseaux, plages d'adresses) et les échanges à remettre dans l'ordre ;
4. terminez par l'examen blanc, à refaire jusqu'au sans-faute (chaque tirage est différent).

## Calculer un sous-réseau

<Theorem type="Méthode">
    Pour une adresse `a.b.c.d/n` :

    1. écrire le masque : $n$ bits à 1 puis des 0 (/26 → 255.255.255.192) ;
    2. repérer l'**octet où passe la frontière** (celui dont le masque n'est ni 255 ni 0) et l'écrire en binaire, ainsi que l'octet correspondant de l'adresse ;
    3. **réseau** : garder les bits de réseau de l'adresse et mettre les bits d'hôte à 0 (ET logique) ;
    4. **diffusion** : mettre les bits d'hôte à 1 ;
    5. **nombre d'hôtes** : $2^{32-n} - 2$.
</Theorem>

{/* AJOUT : raccourci du « pas » (taille de bloc), classique mais absent du cours */}

<Remark titre="Raccourci : le pas du sous-réseau">
    Dans l'octet frontière, les réseaux avancent par pas de $256 - \text{masque}$. Pour /26 (masque 192), le pas vaut 64 : les réseaux commencent à 0, 64, 128, 192. L'adresse 192.168.1.130 tombe dans le bloc qui commence à 128 : réseau .128, diffusion .191 (128 + 64 − 1).
</Remark>

<Exercise titre="10.20.37.200/20" niveau={2}>
    Donnez le masque, le numéro de réseau, l'adresse de diffusion et le nombre d'hôtes.

    <Solution>
        /20 = 8 + 8 + 4 : le masque est **255.255.240.0** et la frontière passe dans le 3e octet. Le pas vaut $256 - 240 = 16$ : les blocs commencent à 0, 16, 32, 48… et 37 tombe dans le bloc 32 à 47.

        - Réseau : **10.20.32.0** ;
        - Diffusion : **10.20.47.255** ;
        - Hôtes : $2^{12} - 2 = 4094$.
    </Solution>
</Exercise>

<Exercise titre="172.16.5.77/27" niveau={1}>
    Donnez le masque, le numéro de réseau, l'adresse de diffusion et la plage des hôtes.

    <Solution>
        /27 : masque **255.255.255.224**, pas de $256 - 224 = 32$. Les blocs commencent à 0, 32, 64, 96… et 77 est dans le bloc 64 à 95.

        - Réseau : **172.16.5.64** ;
        - Diffusion : **172.16.5.95** ;
        - Hôtes : de 172.16.5.65 à 172.16.5.94, soit $2^5 - 2 = 30$ adresses.
    </Solution>
</Exercise>

<Exercise titre="Même réseau ou non ?" niveau={2}>
    Les hôtes 192.168.10.62/26 et 192.168.10.65/26 peuvent-ils communiquer directement, sans routeur ?

    <Solution>
        Le pas vaut 64 : 62 est dans le bloc 0 à 63 (réseau 192.168.10.0), 65 dans le bloc 64 à 127 (réseau 192.168.10.64). Les deux hôtes sont dans **deux réseaux différents** : chacun doit passer par sa passerelle par défaut.
    </Solution>
</Exercise>
